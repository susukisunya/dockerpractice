# dockerpractice  
## 使い方  
このdockerfileは、buildされ、runをされたときに、input.txtに書かれている文字とoutput.txtに書かれている文字が同じかどうかを判定してその結果を出力します。  
同じ文字だったときはAC、違う文字だったときはWAと出力される。  
実行の段階でエラーが発生したときはREと出力する。例えば、input.txtになにも書かれていないときなど。  
Dockerfileをbuildするときは、  
1.#pythonバージョンとコメントアウトした行から#cバージョンとコメントアウトした行までをコメントアウトor削除  
2.#cバージョンとコメントアウトした行から下の行すべてをコメントアウトor削除  
のどちらかをしてからbuildしてください。  
docker runをしたときに、main.cを実行したいときは1を、main.pyを実行したいときは2を行ってください  
同じディレクトリにDockerfileは2つ作れないので、チェックポイントの2をpythonでを行ったものとpython以外で行ったものの両方を一つのdockerfileに記載しました  
## dockerってどう動いてるの?  
dockerとは、コンテナ型の仮想環境を作成したり、配布したり、実行したりできるプラットフォームのこと。  
コンピュータのosに対して、ゲストosがあるようにみせてコンテナのソフトウェアや、ミドルウェアを動かす。  
この記事に出ていた例がわかりやすかった。https://qiita.com/Sicut_study/items/4f301d000ecee98e78c9  
dockerをゲーム機だとすると、コンテナはゲームソフトにあたる。ゲームソフトが同じ種類のどのゲーム機をつかっても同じように動作するように、  dockerのコンテナもどのコンピュータ上でも同じように動作する。  
## dockerを使うと何がいいの？  
どんなコンピュータでも、まったく同じ環境を作成することができる。  
しかも、作成方法も簡単!  
Dockerfileと呼ばれるファイルに書かれたコードからビルドするので、  
Dockerfileさえあればコマンドを打つだけでいい。  
ハッカソンとかでも使えそう  
dockerhubからdocker imageをpullすることで、もうすでに完成している環境を用意することもできる
